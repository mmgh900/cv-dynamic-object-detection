\section{Our approach}

The project asks us to find one moving object in a short sequence of
images and draw a box around it on the first frame. The brief
suggests using sparse local features and either feature matching or
optical flow, so we follow that path.

We watched the videos before writing any code. In four of the five
sequences (bird, frog, sheep, squirrel) the camera does not move at
all. In the car sequence the camera does a small pan from left to
right. So the trick is simple: if we follow some points across the
frames, the points on the background stay still (or all move
together with the camera) and the points on the object move
differently. We just need to spot which points are different.

\paragraph{What we tried first.} We started with SIFT features and
matched them between frame 0 and every later frame using Lowe's
ratio test. It worked for the car and the sheep, but it failed
badly on the squirrel: the squirrel is very small and its fur does
not give SIFT enough stable points, so we got an IoU of $0.31$
which is below the threshold. We switched to optical flow because
the brief allows it and because optical flow does not need a
``perfect'' point, just a corner that the tracker can follow.

\paragraph{What we do now.} The pipeline has five short steps:

\begin{enumerate}\itemsep1pt
\item Find good corners on the first frame
  (\texttt{cv::goodFeaturesToTrack}).
\item Follow each corner from frame to frame using pyramidal
  Lucas--Kanade optical flow (\texttt{cv::calcOpticalFlowPyrLK}). We
  also run the flow backwards as a sanity check and drop any track
  that does not return to where it started.
\item For each frame, take the median displacement of all the
  surviving tracks and call it the camera. Subtract it. What is
  left is real object motion.
\item For each track we get an average leftover motion. We sort
  the tracks and keep the top $15\%$, but only if their motion is
  bigger than $\max(8\,\text{px}, 4\times\text{median})$. The floor
  is what removes leaves moving in the wind, walkers in the
  background, and the nearly-still sheep that the brief tells us to
  ignore.
\item Group the surviving points by distance, take the biggest
  group, throw away points that are too far from the centre, and
  return a slightly padded bounding box. A small extra step uses
  pixel differences to shrink the box if it is clearly too big, but
  it only kicks in when the new box is much smaller than the old one.
\end{enumerate}

\section{Robustness}

\paragraph{Camera motion.} Four sequences have a still camera, the
car has a small pan. We do not try to fit a fancy camera model;
subtracting the median displacement is enough to cancel a constant
shift, and it is what makes the car case work.

\paragraph{Lighting.} Optical flow is sensitive to brightness
changes, but the forward--backward check kills tracks where the
``motion'' is really an illumination artefact. The dappled light
on leaves in the bird and frog sequences does not leak into the
moving set.

\paragraph{Occlusion.} If a track gets covered for a few frames the
flow simply fails for those frames and the track is dropped
temporarily. We average over the frames that did succeed, so a
short occlusion does not destroy the score.

\paragraph{Small or smooth objects.} The squirrel is tiny (about
$1\%$ of the image) and the optical-flow approach is exactly what
saves it: we get only $5$ moving tracks but they all sit on the
squirrel and the box is correct (IoU $0.62$). The frog is the
opposite story: its body is very smooth so we find very few corners
on it, the moving tracks all land on the limbs, and the box ends up
too tight (IoU $0.28$, our only failure). With SIFT this case
worked because the scale-space extrema picked up a few stable
points across the body; we lost it when we switched to corner-based
tracking, but we judged the squirrel recovery to be more valuable.

\paragraph{Sensitivity.} Two parameters mattered. The corner
quality level $0.005$ is permissive enough to find corners on
weakly textured surfaces (squirrel fur) without flooding the
background; $0.01$ lost the squirrel and $0.001$ added grass false
positives on the car. The displacement percentile $15\%$ balanced
recall and precision: $10\%$ missed pieces of the sheep, $20\%$
brought in horizon false positives on the car.

\section{Code and credit}

\paragraph{Code layout.} \texttt{src/feature\_tracker.cpp}
(corners + Lucas--Kanade + median-flow), \texttt{motion\_segmenter.cpp}
(displacement classifier), \texttt{bbox\_estimator.cpp} (clustering
and bounding box), \texttt{silhouette\_refiner.cpp} (optional
shrink), \texttt{evaluator.cpp} (IoU), \texttt{main.cpp} (entry
point), \texttt{include/dod.hpp}, \texttt{CMakeLists.txt}. Build with
\texttt{cmake -S . -B build \&\& cmake --build build}; run with
\texttt{./build/detect dataset output}. OpenCV~4 is the only
dependency. No deep learning.
