\section{Method}

We watched the videos before writing any code. In four of the five
sequences (bird, frog, sheep, squirrel) the camera does not move,
in the car sequence it does a small left-to-right pan. So the idea
is simple: follow some points across the frames, the points on the
background stay still (or all move together with the camera) and
the points on the object move differently. We just need to spot
which points are different.

The pipeline has six steps:

\begin{enumerate}\itemsep1pt
\item Apply local histogram equalisation (CLAHE, clip $0.5$,
  $8\times8$ tiles) to every frame, so the next step can find
  corners on dim or smooth surfaces.
\item Find good corners on the equalised first frame
  (\texttt{cv::goodFeaturesToTrack}).
\item Follow each corner from frame to frame using pyramidal
  Lucas--Kanade optical flow
  (\texttt{cv::cal\-cOpticalFlowPyrLK}). We also run the flow
  backwards as a sanity check and drop any track that does not
  return to where it started.
\item For each frame, take the median displacement of all the
  surviving tracks and call it the camera. Subtract it.
\item For each track we get an average leftover motion. Keep the
  top $15\%$ above $\max(8\,\text{px}, 4\times\text{median})$.
\item Group the surviving points by distance, take the biggest
  group, drop points far from the centre, and return a slightly
  padded bounding box. A small extra step uses pixel differences to
  shrink the box if it is clearly too big.
\end{enumerate}

\paragraph{What we tried first.} Our initial version used SIFT
features matched between frame 0 and every later frame with Lowe's
ratio test. It worked for the car and the sheep but failed on the
squirrel (IoU $0.31$, sub-threshold) because SIFT scale-space
extrema do not anchor on its fur. We replaced the SIFT front-end
with Shi--Tomasi corners + Lucas--Kanade flow because optical flow
does not need a stable scale-space extremum, only a corner the
tracker can follow.

\paragraph{Bird, car, sheep.} These three objects all have plenty
of strong corners on them: dark feathers against bright leaves, a
metal car body, dark sheep legs and a fence. Lucas--Kanade follows
them across the whole sequence, the moving ones stand out from the
still background, and the cluster covers most of the object.

\paragraph{Squirrel.} The squirrel is only about $1\%$ of the
image, so it is the hardest case. With SIFT we got IoU $0.31$;
with Shi--Tomasi corners we get only five moving tracks but they
all sit on the squirrel, so the box is tight and correct (IoU
$0.62$).

\paragraph{Frog.} Without CLAHE the frog was our only failure (IoU
$0.28$). Its body is wet and smooth, almost no local gradient, so
Shi--Tomasi found corners only on the limbs and the branch next to
it. After CLAHE the skin gets a local contrast boost,
Shi--Tomasi places extra corners along the back and sides, and the
box reaches IoU $0.53$. Figure~\ref{fig:clahe} shows the corner
counts before and after.

\section{Code and credit}

\paragraph{Code layout.} \texttt{src/feature\_tracker.cpp}
(corners + Lucas--Kanade + median-flow),
\texttt{motion\_segmenter.cpp} (displacement classifier),
\texttt{bbox\_estimator.cpp} (clustering and bounding box),
\texttt{silhouette\_refiner.cpp} (optional shrink),
\texttt{evaluator.cpp} (IoU), \texttt{main.cpp} (entry point),
\texttt{include/dod.hpp}, \texttt{CMakeLists.txt}. Build with
\texttt{cmake -S . -B build \&\& cmake --build build}; run with
\texttt{./build/detect dataset output}. OpenCV~4 is the only
dependency. No deep learning.
