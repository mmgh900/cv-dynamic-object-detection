\section{Approach}

The pipeline localises the dynamic object in the first frame of each
input sequence by combining sparse feature tracking with a
motion-consistency test based on a global homography. It contains
four stages, each implemented in a dedicated C++ source file:

\paragraph{(1) Feature detection and KLT tracking.}
Shi--Tomasi corners are detected on the first frame
(\texttt{goodFeaturesToTrack}) with quality $0.003$ and an adaptive
minimum distance proportional to the image diagonal so that small
objects (e.g.\ the squirrel) still receive enough samples. Sub-pixel
refinement is applied. Corners are propagated through the sequence
with pyramidal Lucas--Kanade optical flow
(\texttt{calcOpticalFlowPyrLK}, window $21{\times}21$, $3$ pyramid
levels). A forward--backward consistency check (forward then backward
optical flow with a $\sqrt{1.5}$\,px tolerance) discards unreliable
tracks.

\paragraph{(2) Global motion estimation.}
Between every consecutive frame pair we fit a single homography to
\emph{all} alive tracks via \texttt{findHomography} with RANSAC
(threshold $3$\,px). Under the dominant-motion assumption, the
homography represents the background (or camera) motion, so
inliers are background points and outliers are candidates for
independent motion.

\paragraph{(3) Dynamic-track classification.}
For each track we accumulate two signals across the sequence: the
outlier ratio $\rho$ and the mean reprojection residual $\bar r$.
The combined score $s=\rho\cdot\min(\bar r,50)$ captures both ``how
often the track disagrees with the global motion'' and ``how strongly
it disagrees''. We keep the top $15\%$ of tracks by score that also
satisfy mild absolute cuts ($\rho>0.25$, $\bar r>0.3\cdot\tau_\text{RANSAC}$).
Using a relative (top-$k$) criterion removes the need to set a hard
threshold and adapts automatically to sequences with very different
camera motion.

\paragraph{(4) Clustering and bounding box.}
The surviving dynamic points on the first frame are grouped with a
DBSCAN-like proximity clustering (radius $\varepsilon{=}0.08\cdot$
image diagonal, $\text{minPts}{=}3$). The best cluster is chosen by
the sum of outlier weights, then neighbouring clusters whose bounding
boxes lie within $1.2\,\varepsilon$ of the seed are merged to recover
objects whose texture is split across subregions (e.g.\ sheep head
vs.\ body). The bounding box is finally padded by $1/8$ of its size to
include silhouettes that usually carry few corners.

\paragraph{Evaluator.} The last module reads the ground-truth
\texttt{xmin ymin xmax ymax} file, computes IoU per category and writes
one prediction file per sequence plus overlays of tracks, predicted
box, and ground-truth box.

\section{Discussion of Robustness}

\paragraph{Camera motion and illumination.} The homography step absorbs
smooth global camera motion (pan/zoom) and the KLT tracker is fairly
tolerant to moderate illumination changes because it operates on
local intensity gradients with sub-pixel refinement. In the
\texttt{bird} and \texttt{frog} sequences, where the camera is
essentially static but lighting fluctuates, the method localises the
object reliably (IoU $0.60$--$0.64$).

\paragraph{Occlusions.} The forward--backward consistency check drops
tracks that temporarily disappear, which is harmless because the
outlier-ratio criterion accumulates evidence over the whole sequence
and compensates for short disappearances. In the \texttt{sheep}
sequence three sheep move together behind a wire fence; our cluster
merging step is what recovers the full bounding box rather than
fragmenting it onto a single animal.

\paragraph{Small objects.} The \texttt{squirrel} sequence is the hardest
case: the object occupies roughly $23\times31$\,px in a $259\times327$
image and moves only a few pixels between frames. The dynamic
classifier still finds the correct region but with only $6$ points, so
the bounding box shrinks inside the ground truth. This is the one
sequence below the $0.5$ threshold. Potential improvements are:
(i)~increasing the feature density locally around candidate regions,
or (ii)~growing the final box using low-level cues
(colour/edge agreement) once its centre has been located -- both
avenues remain within classical CV and do not require deep learning.

\paragraph{Sensitivity analysis.} We iterated on two design choices:
\begin{itemize}\itemsep0pt
  \item Classifier threshold: fixed outlier-ratio $>0.45$ gave
  mIoU $=0.42$; switching to the top-$15\%$ relative criterion lifted
  it to $0.56$ and accuracy from $0.4$ to $0.8$.
  \item Cluster merge: without merging close clusters, the sheep
  bounding box covered only one animal (IoU $0.36$). With merging it
  reaches $0.65$.
\end{itemize}
